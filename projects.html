academic work

Academic work

Selected coursework from the BEng in Cybersecurity and Forensics at Edinburgh Napier. The code and reports are not published because the target applications and lab environments belong to the university, but I am happy to talk through any of them in detail.

Web application penetration test

2025

Black-box test of a university-provided web application following the PTES methodology: scoping, port scanning, vulnerability scanning, controlled exploitation and a client-style report. Findings included verbose server headers, an internal IP address leaked in redirects, missing HttpOnly cookie flags and weak password rules, each with a risk rating and remediation advice.

PTES Nmap OpenVAS Nikto Burp Suite Metasploit

Securing a vulnerable banking web app

2025

Demonstrated and then fixed vulnerabilities in a deliberately insecure Java banking application, including XSS, SQL injection, IDOR, CSRF, weak session handling, insecure file uploads and code injection. Fixes used prepared statements, input validation and output encoding, CSRF tokens, access checks and safe upload handling, with each fix retested.

Java OWASP Top 10 Burp Suite Secure coding

Blockchain security for campus IoT (Honours project)

2025

Permissioned Hyperledger Fabric network with two organisations recording events from simulated campus devices (card readers, CCTV, CO2 sensors, printers, smart lights). Wrote one smart contract per device type with input validation, duplicate-event rejection and audit history, plus a Node.js gateway receiving sensor data over UDP from a Contiki/Cooja simulation. Evaluated latency and resilience to device impersonation, tampering and denial of service.

Hyperledger Fabric Node.js Contiki / Cooja Docker

Botnet detection with Snort IDS

2023

Built a virtual network with a botnet controller (Ubuntu) and an infected agent (Windows), installed Snort on a Linux server, and configured and tuned detection rules and alerting. Captured the command-and-control traffic in Wireshark to understand it and confirm the alerts fired.

Snort Wireshark Ubuntu Windows Server
