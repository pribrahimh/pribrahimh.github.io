IoT Blockchain System

prototype

Records sensor readings from a simulated IoT network onto a permissioned blockchain so data integrity can be verified rather than assumed. Built with Contiki-NG and Cooja for the sensor layer and Hyperledger Fabric for the ledger. Shell-heavy internals. Repo contains four components: cooja-simulation, backend ingest, Hyperledger Fabric ledger, and a query frontend.
